# FHS — Fresenius Health Services

## FHS Citrix — where to send the ticket

If Helios users encounter issues with or request access to FHS Citrix, they must submit a ticket by contacting it-services@vamed.com.

Contact:
it-services@vamed.com

## Coexisting phase — which account to use

During the coexistence phase two environments run in parallel. Use the account listed per app.

| App | Account | Description | Comment |
|---|---|---|---|
| Laptop login | Fresenius | After the migration, log in to your laptop using your Fresenius account credentials. | Your laptop is now managed by Fresenius. |
| VPN | Fresenius Health Services | To establish a VPN connection use your FHS VPN client. | Temporary solution. You will be informed prior to the planned change. |
| Outlook (desktop) | Fresenius | Use the Outlook desktop app for all your emails. This is the consolidated view (Fresenius + FHS). Do not use Citrix Outlook. | All inbound emails appear in your Fresenius mailbox. Outbound emails come from @fresenius.com with a banner explaining the change to external recipients. |
| Outlook Web App | Fresenius Health Services | Use the Outlook Web App only to access shared mailboxes. | Access via a web browser, logged in with the FHS profile. |
| Teams | Fresenius | Switch to your Fresenius account if required. | Your primary account is the Teams app. |
| Teams (FHS account) | Fresenius Health Services | You can continue your work on your FHS account profile as usual. | Your additional account in Teams. This account must be manually added to your Teams app after the migration. |
| SharePoint | Fresenius | Fresenius SharePoint websites. | Access via a web browser using the Fresenius profile. |
| SharePoint (FHS) | Fresenius Health Services | FHS SharePoint websites. | Access via a web browser, logged in with the FHS profile. |
| OneDrive | Fresenius | Use the Fresenius OneDrive desktop app for all files. The FHS content has been copied. When collaborating you must share the new file link, as colleagues may still be working on the FHS file. | Access via a web browser, logged in with the FHS profile. |
| OneDrive (FHS) | Fresenius Health Services | Use only if you believe files have not been transferred. | Access via a web browser, logged in with the FHS profile. |
| Citrix (FHS) | Fresenius Health Services | Use a web browser to access the FHS Citrix apps. Do not use the Outlook app in Citrix. | Access via a web browser, logged in with the FHS profile. Issues / access requests → it-services@vamed.com. |
