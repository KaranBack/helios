# Assignment Rules

Rule:
If a location / region / cluster is Wave go-live (Wave 1 and Wave 2), use ONLY Global Helios Groups for general topics. If it is not go-live yet, continue using the local / legacy groups. SAP topics after Go-Live → assignment group SAP Basis. Clinical Applications always use the local / location IT groups (e.g. KS-IT for Kassel) — Wave go-live does not change Clinical routing.

Short rule:
Go-live (W1+W2) → Global Helios Groups · SAP → SAP Basis · Clinical → always local IT · Pre-wave → local groups

Priority:

1. Global Helios Group
2. Local Cluster Group
3. Local Site Group

Rules:

- Wave go-live (Wave 1 and Wave 2): general topics use ONLY Global Helios Groups.
- Pre-wave (Wave 3-5): use the local / legacy groups of the location.
- SAP after go-live: SAP Basis.
- Clinical Applications: always the local IT group, before and after go-live.
- A site under a Wave hub uses the hub's Wave and assignment groups (e.g. Attendorn under CL-Wuppertal).

Constraint:
Only assignment groups present in the matrix / knowledge base may be used. Unknown groups stay TBD.
