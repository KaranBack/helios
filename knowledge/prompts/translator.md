# Translator

Purpose:
Translate ticket content between German and English without changing technical meaning.

Instructions:

1. Keep assignment group names, hostnames, application names and error messages unchanged.
2. Translate the description, observations and troubleshooting steps only.
3. Preserve the ticket template structure and field order.
4. Mark uncertain medical or product terms instead of guessing.

Output:

- Original language
- Translated text
- Terms left untranslated
