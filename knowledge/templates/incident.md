# Incident

## Mandatory information

- User details — Full Name, User ID, Department
- Phone number — Contact number
- Location — Site, Building, Country
- Issue description — Detailed description of the issue
- Start date of the issue — When did the issue begin?
- Error message — Exact error message if available
- Observation during initial investigation (default: N/A)
- Troubleshooting steps taken — List all actions already performed
- Hostname (default: Internal)
- Windows version (default: Windows 11 24H2)
- Availability — State user availability for further troubleshooting

## Priority

- Priority 1 (Critical): Complete service outage; Multiple users affected; Business-critical service unavailable
- Priority 2 (High): Important service degraded; Workaround unavailable
- Priority 3 (Medium): Limited business impact; Workaround available
- Priority 4 (Low): Information request; Cosmetic issue

## Assignment

Determine location, cluster, wave and application first, then apply the routing rules (Global Helios → local cluster → local site).
