How to edit this database
  1. Open matrix.html in a text editor.
  2. Find the block starting with const KB = { (near the bottom).
  3. Add a cluster: add an entry under KB.clusters with keys Infrastructure, Clinical, SAP, Account, FieldService, ServiceDesk. Use "TBD" if unknown — those categories will be skipped in Application Base.
  4. Add a location card: append to KB.locationCards.
  5. Add / change an application: edit lists under KB.apps (clinical, infrastructure, sap, account, field).
  6. Berlin-specific group: set override in KB.berlinAz.
  7. Wave 1 keyword: append object to KB.wave1.
  8. Global Helios group: append to KB.globalHelios.
  9. Save and reload the page in a browser.
